# 44. Security Testing Automation and Regression

## Safe automation principles
- Automate repeatable checks against a local fixture or authorized staging target.
- Fail closed on invalid input; enforce an explicit target allowlist.
- Add timeouts, low request rates, logging, and a stop condition.
- Keep secrets out of command history and CI logs.
- Treat scanner output as a hypothesis requiring manual validation.

## Exercise
Run `python labs/local_header_lab.py` in one terminal and `python labs/audit_local_headers.py` in another. The lab binds only to loopback. Review the reported missing headers, then add one header and rerun the checker.

## Regression workflow
1. Reproduce on a safe fixture.
2. Add a test that fails before the fix.
3. Implement the smallest fix.
4. Run tests and inspect the diff.
5. Record remaining limitations and false positives.
