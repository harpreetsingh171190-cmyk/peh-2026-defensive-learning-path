# Module 74 — Log Analysis and Security Data Pipelines

## Goal
Collect, normalize and retain logs so detections are reliable and evidence stays trustworthy.

## Topics
- Common fields: timestamp (UTC), actor, source, action, outcome, target, request ID.
- Normalization: one schema across Windows, Linux, cloud and application logs.
- Time: NTP sync, time zones, ordering across systems.
- Integrity and retention: append-only storage, access control, retention matched to legal and operational needs.
- Privacy: minimize personal data, mask secrets at the source, restrict who can search.

## Lab
- Extend `labs/sample-auth-events.jsonl` with 10 more **synthetic** events using documentation-reserved IPs (`192.0.2.0/24`, `198.51.100.0/24`).
- Write a validator that rejects events missing required fields or with non-UTC timestamps.

## Self-check
Can another analyst reproduce your conclusion from the retained logs alone?
