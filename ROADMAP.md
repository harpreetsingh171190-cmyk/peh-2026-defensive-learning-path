# Roadmap

Planned directions (subject to change; contributions welcome via [CONTRIBUTING.md](CONTRIBUTING.md)).

## Next
- Per-module learning objectives and estimated study time.
- More offline labs with synthetic datasets (cloud audit logs, container manifests).
- Dashboard: per-module notes and a printable progress summary.

## Later
- Optional static documentation site generated from the Markdown modules.
- Translated glossaries maintained as separate, clearly labeled packages.
- Community review process for module accuracy and freshness (tool versions, standards).

## Principles
Defensive framing, authorization first, synthetic data, offline-first tooling, reproducible quality gates.
