# Module 80 — Home and Small-Office Network Hardening

## Goal
Apply defensive basics to a network you own.

## Checklist
- [ ] Change default router admin credentials; update firmware; disable unused remote administration.
- [ ] WPA3 (or WPA2-AES) with a long unique passphrase; separate guest and IoT networks.
- [ ] Turn off WPS and unused port forwards/UPnP.
- [ ] Automatic OS and browser updates; password manager; passkeys or app-based MFA.
- [ ] 3-2-1 backups with a periodic restore test.
- [ ] Review connected devices monthly and remove unknown ones.

## Lab
Inventory your own devices, rate each by exposure and data value, and record fixes in `labs/sample-risks.csv` format. Rank them with `python labs/risk_register.py your-file.csv`.
