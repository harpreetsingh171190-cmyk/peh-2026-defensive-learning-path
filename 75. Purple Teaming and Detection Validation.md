# Module 75 — Purple Teaming and Detection Validation

## Goal
Prove that detections work by pairing a documented, authorized test with the defensive signal it should produce.

## Process
1. Pick one ATT&CK technique relevant to your lab and write the **detection hypothesis**.
2. Define the expected log source and fields before testing.
3. Run the minimum authorized test in an isolated lab (use benign simulation, e.g. synthetic events, not live malware).
4. Record: detected / partially detected / missed, and why.
5. Fix the gap (logging, rule, response) and **re-test**.

## Rules
Written scope first, synthetic data, no production systems, stop on any scope doubt.
