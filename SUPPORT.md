# Support

- **Questions about the material:** open a GitHub Discussion or an issue using the "Content suggestion" form.
- **Bugs in labs or the dashboard:** use the "Bug report" form and include OS and Python/browser versions. Never paste secrets or personal data.
- **Security concerns:** follow [SECURITY.md](SECURITY.md).
- **Not supported:** help testing systems you do not own or are not authorized to assess.

This is a volunteer-maintained learning resource; responses are best effort.
