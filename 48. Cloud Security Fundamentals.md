# 48. Cloud Security Fundamentals

## Learning outcomes
- Explain shared responsibility and why it varies by service.
- Review IAM, network exposure, storage permissions, audit logs and backups.
- Build a repeatable review checklist for an account you own or are explicitly authorized to assess.

## Safe review workflow
1. Confirm account ownership, written scope, allowed regions and change window.
2. Use a dedicated learner account and least-privilege read-only role where possible.
3. Inventory assets, identities, public endpoints, storage access and logging coverage.
4. Compare settings with the provider's current official baseline.
5. Record finding, evidence with secrets redacted, impact, remediation and retest result.
6. Do not test production availability, access other tenants' data, or attempt privilege escalation without explicit written authorization.

## Checklist
- MFA for privileged accounts; no shared administrator accounts.
- Least-privilege IAM policies; remove unused identities and credentials.
- Public storage and network access disabled unless explicitly required.
- Audit logs enabled, retained and protected against tampering.
- Encryption and key rotation policies match data sensitivity.
- Tested backups and documented recovery objectives.
- Cost alerts and ownership tags enabled.

## Exercise
Create a fictional cloud architecture diagram. Identify five trust boundaries and write one preventive control and one detection control for each. Do not create resources that incur charges unless you have checked the cost first.
