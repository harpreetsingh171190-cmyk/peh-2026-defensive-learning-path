# Security Glossary

| Term | Meaning |
|---|---|
| Authorization | Written permission and agreed scope to test or access a system |
| Scope | The systems, methods and time window that are approved |
| Vulnerability | A weakness that could be misused to harm confidentiality, integrity or availability |
| Risk | Likelihood of harm combined with its impact |
| Threat model | A structured analysis of assets, trust boundaries and likely abuse cases |
| Alert | A notification produced when a rule or detection matches |
| Incident | A confirmed event that harms or threatens security and needs response |
| Triage | Deciding what to investigate first and why |
| Chain of custody | Record of who handled evidence, when and why |
| Least privilege | Granting only the access needed for a task |
| MFA | Authentication using more than one kind of proof |
| Passkey | Phishing-resistant credential bound to a device or account |
| SBOM | Software bill of materials: a list of components in software |
| Remediation | Fixing a finding and verifying the fix |
| Tabletop exercise | Discussion-based rehearsal of an incident using a fictional scenario |
| Synthetic data | Made-up data used for safe practice |
| CVSS | A scoring system describing the technical severity of a vulnerability |
