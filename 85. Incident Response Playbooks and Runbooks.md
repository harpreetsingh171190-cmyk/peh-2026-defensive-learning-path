# Module 85 — Incident Response Playbooks and Runbooks

## Goal
Turn lessons from triage and tabletop exercises into repeatable, reviewable procedures.

## Playbook structure
1. **Trigger:** which alert or report starts this playbook.
2. **Roles:** incident lead, scribe, technical responder, communications, business owner.
3. **Decision points:** contain now or observe? escalate? notify?
4. **Steps:** numbered, owner-assigned, with expected evidence at each step.
5. **Exit criteria:** what must be true to close the incident.
6. **Review:** blameless post-incident review with dated action items.

## Lab
Using `labs/detection_rules.py`, pick one rule that fires on the synthetic data and write a one-page playbook for it. Run it as a 30-minute tabletop with a friend or study group.

## Self-check
Could someone new follow your playbook at 3 a.m. without asking you questions?
