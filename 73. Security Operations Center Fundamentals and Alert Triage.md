# Module 73 — SOC Fundamentals and Alert Triage

## Goal
Learn how defenders turn raw logs into decisions. Work only with the synthetic data in `labs/`.

## Core concepts
- **Event vs alert vs incident:** an event is a record, an alert is a rule match, an incident is a confirmed impact needing response.
- **Triage questions:** Who? What asset? What changed? Is it expected? What is the blast radius?
- **Severity vs priority:** severity is technical impact; priority also weighs asset value, exposure and business timing.
- **False positives:** record why an alert was benign so the rule can be tuned, not silenced.

## Lab
1. Run `python labs/detect_auth_anomalies.py`.
2. For each flagged identity, write a 5-line triage note: evidence, hypothesis, confidence, next check, escalation decision.
3. Tune the threshold in the script, re-run the tests, and document the trade-off between missed detections and noise.

## Deliverable
A triage note using `templates/incident-timeline-template.md`. Never include real usernames, IPs or tokens.
