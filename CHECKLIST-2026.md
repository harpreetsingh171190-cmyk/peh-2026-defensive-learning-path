# 2026 Course Quality and Safety Checklist

- [ ] Confirm written authorization and scope before each practical.
- [ ] Use isolated, disposable labs and synthetic data.
- [ ] Verify tool installation steps against official docs at the time of use.
- [ ] Record OS, tool, and dependency versions in each lab note.
- [ ] Run static checks on code before executing it.
- [ ] Review output for accidental secrets and personal data.
- [ ] Distinguish confirmed findings from hypotheses.
- [ ] Add remediation and verification steps to every finding.
- [ ] Include detection and defensive validation, not just exploitation.
- [ ] Revert or tear down the lab after each session.
- [ ] Keep the original course attribution and license notices intact.
