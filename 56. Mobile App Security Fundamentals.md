# 56. Mobile App Security Fundamentals

## Learning goals
- Understand mobile threat boundaries and platform security.
- Review storage, network traffic, permissions, authentication and exported components.
- Avoid treating client-side checks as trusted enforcement.

## Defensive review
- Store sensitive data only when necessary; use platform-backed secure storage for suitable secrets.
- Never embed server-wide API secrets in an APK or app bundle.
- Use modern TLS and do not disable certificate validation to “fix” test failures.
- Request only permissions needed for a clear feature.
- Ensure server-side authorization protects every sensitive operation.
- Avoid logging tokens, personal information or private request bodies.
- Review deep links, exported components, backup settings and WebView content handling.
- Keep dependencies and target SDKs updated; verify signing and release processes.
- Provide a privacy notice that matches actual collection and retention.

## Lab
Use an app you own or an intentionally vulnerable training app. Create synthetic test accounts, inspect its permission list and logs, then document one privacy improvement. Do not extract data from someone else's device or account.
