# Practical Ethical Hacking — 2026 Roadmap

This roadmap supplements the original course notes. It is not a certification and does not imply that every legacy command has been revalidated.

## 12-week flexible plan
| Week | Focus | Portfolio output |
|---|---|---|
| 1 | Networking, Linux, shell, Git | network notes + command glossary |
| 2 | Python basics and safe automation | small parser for synthetic logs |
| 3 | Methodology, scope, evidence | authorization and test-plan template |
| 4 | Recon and scanning concepts | local lab asset inventory |
| 5 | Web fundamentals and OWASP WSTG | test checklist for a local app |
| 6 | API authorization and identity | API threat model |
| 7 | Active Directory fundamentals | isolated lab notes and hardening list |
| 8 | Containers and cloud basics | Docker hardening checklist |
| 9 | AI/LLM application security | prompt-injection risk assessment using dummy data |
| 10 | Android app security | manifest/permissions review of an owned demo app |
| 11 | Detection and incident response | synthetic-log detection + tabletop |
| 12 | Capstone, reporting, interview practice | sanitized GitHub portfolio |

## Each study session
- [ ] Read one short topic.
- [ ] Reproduce only in a local/authorized lab.
- [ ] Write down assumptions and expected result before testing.
- [ ] Capture sanitized evidence.
- [ ] Explain impact and remediation in plain language.
- [ ] Commit notes without secrets.

## Suggested time budget
30–60 minutes per session is enough for steady progress. Take breaks and repeat exercises instead of rushing through tools.
