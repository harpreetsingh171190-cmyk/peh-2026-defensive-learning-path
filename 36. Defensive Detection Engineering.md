# 36. Defensive Detection Engineering

## Outcomes
- Build detections from observable behavior, not just tool names.
- Understand false positives, false negatives, and coverage gaps.
- Document a safe validation plan.

## Detection workflow
1. State the behavior and threat hypothesis.
2. Identify required telemetry and its limitations.
3. Write a human-readable detection idea and expected fields.
4. Test against synthetic sample logs.
5. Record true positives, false positives, and missed cases.
6. Add a response playbook and rollback/containment notes.

## Mini-lab
Use `labs/sample-auth-events.jsonl`. Find repeated failures followed by a success for the same synthetic account and source. Explain why this is a signal, not proof of compromise. Add a threshold, time window, exclusions, and escalation steps.

## Deliverable
A detection rule in plain language, test cases, sample events, expected results, and a one-page triage runbook.
