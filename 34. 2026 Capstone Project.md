# 34. 2026 Capstone Project

## Scenario
You are assessing a small demo organization that owns a local web app, a JSON API, an Android training app, and a containerized service. All targets are intentionally vulnerable or created by you.

## Rules of engagement
- Scope: local VMs, emulator, and services bound to loopback/private lab network.
- Accounts and records: synthetic only.
- No public IP scanning, real credentials, persistence, destructive testing, or third-party targets.
- Stop immediately if the lab affects another device or network.
- Record all test actions and clean up when finished.

## Work packages
### A. Reconnaissance and asset inventory
List only lab assets, versions, routes, ports, roles, and trust boundaries.

### B. Web/API testing
Test authentication, object-level authorization, input validation, rate limiting, and sensitive error messages. Use dummy records and non-destructive test cases.

### C. Container review
Review image source, user privileges, exposed ports, mounts, secrets handling, and dependency report.

### D. AI feature review
If you build a local chatbot, test untrusted document instructions, access isolation, output validation, and tool permission boundaries using mock tools.

### E. Android review
Review the manifest, storage, permissions, deep links, and network configuration in a training APK.

### F. Detection
Create a timeline from lab logs and propose one useful detection rule with known limitations.

## Deliverables
- `scope.md`
- `asset-inventory.csv`
- `test-plan.md`
- `findings.md`
- sanitized evidence folder
- remediation checklist
- retest results
- 5-minute portfolio walkthrough (no secrets or real targets)

## Evaluation rubric
| Area | Points |
|---|---:|
| Scope, safety and reproducibility | 20 |
| Quality of evidence | 20 |
| Technical accuracy | 20 |
| Risk prioritization | 15 |
| Practical remediation and retest | 15 |
| Clear report and portfolio hygiene | 10 |

Passing means that another learner can reproduce your findings safely and understand how the fixes were verified.
