# Module 77 — Security Automation with Python (Safely)

## Goal
Automate defensive and reporting tasks with code that is testable and scope-limited.

## Safe-by-design checklist
- [ ] Allow-list targets (loopback or explicit lab ranges) and fail closed.
- [ ] No hard-coded secrets; read from environment or a secrets manager.
- [ ] Timeouts, rate limits and dry-run mode by default.
- [ ] Unit tests for the safety guard itself (see `labs/test_audit_local_headers.py`).
- [ ] Structured output (JSON) and meaningful exit codes for CI.
- [ ] Logging that omits secrets and personal data.

## Practice
Read `labs/detect_auth_anomalies.py` and add: CSV export, a `--threshold` option, and a test for each new behavior.
