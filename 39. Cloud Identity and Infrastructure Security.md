# 39. Cloud Identity and Infrastructure Security

## Core concepts
- Shared responsibility, IAM roles/policies, federation, MFA, workload identity.
- Public exposure, storage permissions, network boundaries, audit logs.
- Infrastructure-as-Code review and drift detection.
- Cloud metadata services and workload identity risks (conceptual study only).

## Safe lab
Use a provider's official sandbox or a local mock configuration. Do not create billable resources without checking costs. Do not test against a real tenant unless authorized.

Review a sample policy for:
- wildcard actions/resources,
- privilege escalation paths,
- public access,
- missing logging,
- long-lived credentials.

## Deliverable
A least-privilege policy proposal, threat notes, audit evidence, and teardown checklist.
