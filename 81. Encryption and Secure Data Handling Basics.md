# Module 81 — Encryption and Secure Data Handling Basics

## Goal
Understand how to protect data at rest, in transit and in use, using well-reviewed standards rather than home-made schemes.

## Key ideas
- **In transit:** TLS everywhere; verify certificates; redirect HTTP to HTTPS.
- **At rest:** full-disk encryption and application-level encryption for sensitive fields.
- **Hashing vs encryption:** hashes verify integrity or store password verifiers (with a slow, salted algorithm); encryption is reversible with a key.
- **Key management:** separate keys from data, rotate, restrict access, and log key use.
- **Never invent your own cryptography;** use maintained libraries and current official guidance.
