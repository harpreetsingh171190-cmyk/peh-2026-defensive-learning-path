# 59. Windows and Linux Hardening Baselines

## Learning goals
Build repeatable baseline checks and explain every change before applying it.

## Baseline checklist
- Inventory operating system, version, role, owner, and business purpose.
- Apply supported security updates after testing and define rollback steps.
- Remove or disable unnecessary services and accounts; preserve required dependencies.
- Require MFA for remote/admin access where supported; use least privilege and separate admin accounts.
- Configure host firewall rules from an explicit allowlist.
- Enable security logging, time synchronization, and protected log retention.
- Encrypt devices and backups where appropriate; test recovery.
- Review SSH/RDP exposure and restrict management access to trusted paths.
- Set secure browser, scripting, and application policies appropriate to the environment.
- Document exceptions with an owner and expiry date.

## Safe audit commands
Linux: `uname -a`, `id`, `ss -lntup`, `systemctl --type=service --state=running`.
Windows PowerShell: `Get-ComputerInfo`, `Get-LocalUser`, `Get-NetFirewallProfile`, `Get-HotFix`.

These commands are for inventory on systems you administer. Review results before making changes; service names and available commands vary by OS version.

## Exercise
Create a before/after checklist for a disposable local VM. Make one low-risk change at a time, capture evidence, validate application health, and document rollback. Never apply a generic hardening script blindly to a production system.
