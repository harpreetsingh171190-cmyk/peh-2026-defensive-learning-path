# 53. API Security and Authorization Testing

## Learning goals
- Distinguish authentication from authorization.
- Understand object-level and function-level access control.
- Review API schemas, error handling, rate limits and data minimization.
- Produce safe, reproducible findings.

## Review checklist
1. Confirm written permission, exact hosts, accounts, test window and request limits.
2. Identify API versions and documented endpoints from approved sources.
3. For each endpoint, record the required role and data owner.
4. In a staging/local environment, verify that user A cannot access user B's test object.
5. Check whether responses expose fields unnecessary for the client.
6. Review pagination, rate limits, error messages, CORS policy and token expiry.
7. Re-test fixes with regression tests and record evidence without secrets.

## Core concepts
- **Authentication:** who is making the request?
- **Authorization:** may that identity perform this action on this object?
- **BOLA/IDOR:** object-level authorization is missing or incorrect.
- **Mass assignment:** untrusted fields can modify properties the caller should not control.
- **Excessive data exposure:** the API returns more information than needed.

## Exercise
Create a toy API with two synthetic users and two synthetic records. Write tests proving each user can read their own record but receives a denied response for the other user's record. Never use real user data.

## Report template
Endpoint and method; role used; expected behavior; actual behavior; minimal synthetic evidence; impact; fix recommendation; regression test; scope confirmation.
