# 45. Secure Configuration and Hardening

## Baseline checklist
- Remove unused services and default accounts where safe.
- Apply supported security updates through official channels.
- Use least privilege and MFA for administrative access.
- Restrict inbound network exposure; prefer host-only networks for vulnerable VMs.
- Enable relevant logs and protect them from unauthorized modification.
- Back up important data and test restoration.
- Store secrets in a dedicated secret store or protected environment configuration.
- Review cloud, container, and repository permissions periodically.

## Hardening report
Record system/version, baseline source, current setting, risk, recommended value, operational impact, test evidence, owner, and rollback plan. Do not blindly apply settings to production systems.
