# Security Policy

## Scope
This repository contains educational material and small offline lab scripts. It has no
production service. Reports are still welcome for: unsafe guidance, scripts that could reach
beyond their documented scope, secrets accidentally committed, and dashboard bugs.

## Reporting a vulnerability
Please use GitHub's private vulnerability reporting ("Security" tab > "Report a vulnerability")
or open an issue that contains **no sensitive details** and ask for a private channel.
Do not post secrets, personal data, or working exploit code against third parties.

## What to expect
- Acknowledgement within 7 days (best effort).
- A fix or documented decision, and credit if you wish.

## Safe-use reminder
Test only systems you own or have written authorization to assess. See
[ETHICS-AND-ACCEPTABLE-USE.md](ETHICS-AND-ACCEPTABLE-USE.md).
